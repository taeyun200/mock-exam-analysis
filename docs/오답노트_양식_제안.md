# 오답노트 양식 제안 — 메타인지적 오답 분석을 위한 설계

목적: 틀린 문항을 "왜 틀렸는가"의 수준에서 분석해 같은 실수를 반복하지 않게 하는 것. 문항·정답·해설·분류는 시스템이 채우고, 학생은 **생각만** 적게 한다.

## 1. 용어와 배경 (영어 번역)

| 한국어 | 영어 | 비고 |
|---|---|---|
| 오답노트 | error notebook / mistake notebook / wrong-answer notebook / error log | 중국 錯題本(cuòtíběn), 일본 間違いノート와 같은 계열 |
| 오답 원인 분석 | error analysis / error attribution | |
| 메타인지 | metacognition (monitoring + control) | |
| 시험 후 성찰지 | exam wrapper (post-exam reflection) | 미국 대학에서 쓰는 서구식 대응물 |
| 다시 풀기 | retrieval practice / re-solving | |
| 간격 복습 | spaced review | |
| 자기 설명 | self-explanation | 정답이 왜 정답인지, 오답이 왜 오답인지 말로 풀기 |

오답노트는 동아시아 입시 문화에서 학습 관행으로 발달했고(錯題本·間違いノート·오답노트), 서구에서는 같은 기능을 exam wrapper(Lovett, 2013)나 error log로 부른다. 두 전통이 가리키는 핵심은 같다: **문항 수집이 아니라 원인 기록**.

## 2. 조사에서 건진 설계 원칙

1. **원인은 구체적으로, "실수"는 금지어.** 中文 자료의 3분류 규칙이 실용적이다. 그 자리에서 다시 풀어 맞으면 *실수형*, 개념을 말로 설명 못 하면 *개념형*, 첫 단계에서 막히면 *방법형*. "부주의"라고 쓰면 다음 행동이 없다.
2. **확신도를 기록한다.** 자신 있게 틀린 답일수록 교정 효과가 크다(hypercorrection effect, Butterfield & Metcalfe 2001; Metcalfe 2017 리뷰). 틀린 문항마다 "확신 / 반반 / 찍음"을 받으면 복습 우선순위가 생긴다.
3. **왜 틀렸는지 + 왜 맞는지 둘 다 쓴다.** 오답 선지가 왜 오답인지 설명하는 자기 설명은 이후 같은 오류를 막는다(Chi 1989/1994; 오류 풀이 설명 연구). 단, 기초가 약한 학생에게는 부담이 되므로 칸을 작게.
4. **답을 가리고 다시 푼다.** 정답을 보고 "이해했다"는 느낌은 믿을 수 없다. 당일·3일·7일 재풀이 체크가 노트의 일부여야 한다(錯題本 복습 리듬 1·3·7).
5. **기록 비용을 낮춘다.** 문항·정답·해설·단원·전국 정답률은 시스템이 채운다. 학생이 고르는 태그는 문항당 최대 2개.
6. **시험 단위 성찰(exam wrapper)을 끝에 둔다.** 준비 → 시험 중 일어난 일 → 다음에 바꿀 것, 세 질문. 효과 연구는 "보통·불안정"이지만 비용이 거의 없고 오답 태그 집계와 결합하면 의미가 생긴다.
7. **반복이 신호다.** 같은 원인 태그가 2회 이상이면 실수가 아니라 습관이다. 노트가 집계를 보여 줘야 한다.

근거의 한계: 오답노트 자체의 효과를 직접 검증한 동료심사 연구는 찾지 못했다. 위 원칙은 오류 학습·메타인지·자기 설명 연구와 錯題本·間違いノート 실무 지침을 합친 것이다.

## 3. 공통 틀 (모든 과목)

```
┌ 문항 카드 ───────────────────────────────────────────────┐
│ [시스템이 채움] 회차·과목·번호·배점 | 영역 > 단원 | 출제의도  │
│                 전국 정답률 A~E · 충북 정답률 · 우리 학교     │
│                 문항 그림 (지문 포함) · 내 답 · 정답          │
├ 학생이 쓰는 칸 ─────────────────────────────────────────────┤
│ ① 그때 확신도   ○ 확신  ○ 반반  ○ 찍음                       │
│ ② 다시 풀기     답 가리고 재풀이 → ○ 맞음  ○ 틀림             │
│ ③ 원인 태그     (과목별 목록에서 최대 2개)                     │
│ ④ 한 줄 원인    "실수"가 아니라 어디서 어떻게 → 예: 조건 (나)를 안 읽음 │
│ ⑤ 근거          정답의 근거 문장/식 한 줄, 내가 고른 선지가 틀린 이유 한 줄 │
│ ⑥ 다음에 할 것  행동 하나 (예: 보기 ㄱㄴㄷ는 하나씩 O/X 표시)  │
│ ⑦ 복습 체크     □ 당일  □ 3일  □ 7일   (각 □ 뒤에 맞음/틀림)   │
└──────────────────────────────────────────────────────────┘
```

출력 끝에 **시험 성찰(exam wrapper)** 반 쪽:
- 준비: 어떻게 준비했나 (시간, 방법)
- 시험 중: 시간 배분, 찍은 문항 수, 자신 있었는데 틀린 문항 수(①에서 자동 집계)
- 원인 집계: 태그별 문항 수 (시스템 집계), 반복 태그 표시
- 다음 시험까지 바꿀 것 두 가지

## 4. 영역별 디자인

과목·영역은 EBSi 분류(item_units.area)를 따른다. 각 영역마다 (a) 원인 태그, (b) 근거 칸의 모양, (c) 시스템이 덧붙이는 정보가 다르다.

### 4-1. 국어

**독서(비문학)** — 오답의 대부분이 지문보다 선지에서 난다.
- 태그: `정보 못 찾음(사실)` · `추론 과잉/부족` · `선지 덫: 주체 바꿈` · `선지 덫: 범위·정도 과장` · `선지 덫: 인과 역전` · `지문에 없는 내용` · `<보기> 적용 실패` · `시간 부족`
- 근거 칸: 지문 그림 위에 **근거 문장 번호**를 적는 칸 (문단-문장, 예: 3-2). 내가 고른 선지에서 **틀린 단어에 동그라미**.
- 시스템: 출제의도(사실적/추론적/비판적 이해)를 태그 옆에 표시해 "어느 수준에서 무너졌는지" 보이게.

**문학** — 작품 파악과 <보기> 적용이 갈린다.
- 태그: `화자/인물·상황 파악 실패` · `표현·서술상 특징 오판` · `<보기> 관점으로 못 읽음` · `시어·구절 의미 오해` · `갈래 지식 부족` · `선지 과잉 해석`
- 근거 칸: 선지의 **주장 부분 / 근거 부분**을 나눠 어디가 틀렸는지 표시 (예: "~을 통해 ~을 드러낸다"에서 앞인지 뒤인지).

**화법·작문** — 조건 문제.
- 태그: `조건 누락` · `자료 활용 방식 오해` · `발화 의도 오독` · `고쳐쓰기 기준 혼동`
- 근거 칸: 문제에 제시된 **조건을 번호로 쪼개** 어느 조건을 놓쳤는지 체크.

**문법** — 개념형이 대부분.
- 태그: `개념 모름` · `개념 혼동(둘을 바꿈)` · `예시 적용 실패` · `<보기> 설명 오독`
- 근거 칸: 해당 규칙을 **내 말로 한 줄** (자기 설명). 시스템은 해설 그림을 바로 아래 붙임.

### 4-2. 수학 — Newman 단계 + 개념

- 태그(풀이 단계): `문제 읽기(조건 누락)` · `이해(무엇을 구하는지)` · `식 세우기(변환)` · `계산·절차` · `답 표기(단답형 칸·단위)` + 개념형 `개념 모름` · `공식 혼동`, 그리고 `시간 부족`, `풀다 포기`
- 근거 칸: **막힌 지점을 풀이 과정 위에 표시**하는 칸. 다시 풀기 결과가 "맞음"이면 자동으로 실수형 후보로 표시.
- 시스템: 단답형(22~30번)은 답 표기 오류를 따로 세어 보여 줌. 해설 그림 아래에 "내 풀이 어디까지 맞았나" 체크 줄.

### 4-3. 영어 (2026-11-14 구현: note_v2.py `card_en`)

조사 근거 — 영어 독해·듣기의 메타인지 연구에서 가져온 것:
- **이해 점검(comprehension monitoring)**: 능숙한 독자는 "어디서 이해가 끊겼는지"를 스스로 알아차리고 되돌아간다. 미숙한 독자는 끊긴 줄도 모른 채 끝까지 읽는다(Spanish EFL monitoring failure 연구, Iranian EFL think-aloud 연구). → **①이해가 끊긴 문장 번호 + 이유(단어/구조/앞뒤 연결)** 칸.
- **MARSI(Mokhtari & Reichard 2002)**의 문제해결 전략: 모르는 단어 뜻을 문맥에서 추측, 어려운 부분을 되읽기·속도 조절. 지원 전략: 바꿔 말하기(paraphrase)·요약. → **②글을 우리말 한 문장으로** 칸(담화 수준 이해를 스스로 확인), **어휘 표: 문맥 추측 뜻 → 사전 뜻 순서**(추측을 먼저 쓰게 해 발견 전략을 훈련하고, 확인으로 고정 — 어휘 발견 전략은 추측과 사전 확인 둘 다 효과, Schmitt 분류).
- **어휘 기록**: 단어 하나가 아니라 **지문 속 구절(연어)**과 함께 적고, 뒤에 다시 꺼내 보는(retrieval) 전제. 1·3·7일 복습 규칙과 결합.
- **세 기둥 진단(어휘·구문·논리)**: 수능 영어 오답의 통상 분류. 원인 유형 1~3번이 이 셋, 4~6번이 선지 덫·유형 전략·시간.
- **구문**: 긴 문장 하나를 완전히 — 베끼고 끊고 S·V 표시 → 우리말. 한 문항에 한 문장만(양보다 완결).

**듣기(1~17)는 오답노트에서 뺀다** (2026-11-14 결정). 독해만 만든다.

**독해(18~45)** — 한 쪽 구성 (선지별 정리는 없음 — 영어는 선지 비교보다 지문 자체를 읽어 내는 쪽이 먼저)
- 문항 그림 | 오른쪽 한 상자에: 읽기 점검(①이해가 끊긴 문장 번째·이유 ②글을 우리말 한 문장으로 ③정답 근거 문장·내 답과 충돌하는 문장 ④이 유형을 푸는 순서) + 확신도 + 원인 유형(어휘 / 구문 / 논리 / 선지 덫 / 유형 전략 없음 / 시간)
- 지문 해석 칸: 끊긴 문장부터 사전 없이 먼저 쓰고, 해설지 해석과 비교해 틀린 곳에 표시
- 단어·관용어 6줄(단어·관용어 / 사전 뜻 / 지문 속 구절(예시 문장))
- 뒷면(한 문항 = 한 장 양면): EBS 오답 강의 정리 한 쪽. 표지·지문 쪽은 빈 '메모' 쪽을 끼워 짝수로 맞춰 문항이 늘 앞면에서 시작
- 지문 쪽: 국어와 같은 방식(41~42, 43~45처럼 실제 지문이 있는 세트만; [31~34] 같은 지시문 한 줄짜리는 쪽을 만들지 않음)

### 4-4. 통합사회

- 태그: `개념 혼동(비슷한 둘)` · `사례→개념 연결 실패` · `자료(표·그래프) 해석` · `보기 ㄱㄴㄷ 하나 오판` · `사상가·관점 혼동` · `시간 부족`
- 근거 칸: **보기 항목별 O/X와 한 단어 이유** (ㄱ O 이유 / ㄴ X 이유…). 자료 문제는 자료에서 읽어야 했던 수치 한 줄.
- 시스템: 단원(예: 윤리 / 지리 / 일반사회)별 집계가 영역 분포로 표시.

### 4-5. 통합과학

- 태그: `개념 모름` · `개념 혼동` · `자료·실험 해석` · `계산·단위` · `보기 ㄱㄴㄷ 하나 오판` · `조건 누락(단, ~를 무시)`
- 근거 칸: 통합사회와 같은 보기별 O/X + 이유, 계산 문제는 식 한 줄.
- 시스템: 물리·화학·생명·지구 영역별 집계.

### 4-6. 한국사

- 태그: `시기 혼동` · `인물·사건 연결 실패` · `사료 해석` · `선지 키워드 함정` · `지도·자료 읽기`
- 근거 칸: 사료에서 **시기를 알려준 단서 단어** 하나, 정답 선지의 키워드 하나.
- 시스템: 단원(시대)별 집계.

## 5. 출력물 구성 (한 학생, 한 회차)

1. 표지: 회차·학생, 과목별 틀린 수, **확신하고 틀린 문항 수**, 반복 태그 경고
2. 과목별 문항 카드 (위 4의 영역별 양식), 같은 지문의 문항은 지문 한 번만
3. 시험 성찰(exam wrapper) 반 쪽
4. (회차가 쌓이면) 원인 태그 추이 표: 회차 × 태그

화면용은 태그를 클릭으로 고르고 저장, 인쇄용은 체크박스. 저장된 태그·확신도·재풀이 결과가 다음 회차의 "반복" 판정과 추이 표의 재료가 된다.

## 6. 확정이 필요한 것

- 태그 목록의 단어와 개수(영역당 5~8개 유지 권장)
- 확신도 3단계 vs 4단계
- 복습 주기(1·3·7일) 체크를 종이에 둘지 화면에만 둘지
- 성찰지를 매 회차 강제할지 선택으로 둘지
