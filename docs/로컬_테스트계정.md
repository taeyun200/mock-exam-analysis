# 로컬 개발 서버 테스트 계정 (wrangler dev --local, 로컬 D1 전용)

실제 사이트(mock-exam.kimtae200.workers.dev)와는 무관한 가짜 값. 로컬 D1(.wrangler/state)에만 들어 있다.

| ID | 비밀번호 | 역할 | 학교 |
|---|---|---|---|
| admin | test1234 | 관리자 | S1 테스트고 |
| S2 | school2pw | 학교 | S2 다른고 |

- 로컬 자료: 회차 2026-03(고1·고2 정답표), S2 학교의 2026-03 고1 6과목 응답 190행(무작위). 리포트를 보려면 회차를 열어야 한다:
  `npx wrangler d1 execute mock-exam --local --command "update exams set is_open=1 where exam_code='2026-03'"`
- 계정 추가·비밀번호 변경: `node account.js <ID> <비밀번호> [school|admin]` 가 찍어 주는 SQL을 `--local` 로 실행.
- 실제 사이트 관리자 비밀번호는 여기 적지 않는다.
